# ♻️ Recyclix AI - Prototype Submission

## 🌍 About The Project
Recyclix AI is a "Clean, Smart, and Sustainable" web platform designed to revolutionize waste management through Artificial Intelligence. This prototype demonstrates a high-fidelity, interactive frontend that uses real-time Machine Learning to classify waste and visualize municipal recycling data.

## 🚀 Key Features
- **Real-Time AI Vision**: Uses **TensorFlow.js** and the **MobileNet** CNN model directly in the browser to accurately classify images of waste (Plastic, Organics, E-Waste, etc.) via webcam or file upload. 
- **Interactive Data Dashboards**: Utilizes **Chart.js** to render real-world metrics representing waste processing and segregation efficiency (localized to Bhopal Zonal Data).
- **Responsive "Glassmorphism" UI**: Built with custom Vanilla CSS featuring floating particle backgrounds, deep shadows, and animated holographic scanning grids.
- **Zero-Backend Architecture**: The entire prototype runs purely on the client-side, making deployment and testing instant and seamless without requiring Python or Node.js servers.

## 🛠️ Tech Stack
- **Structure / Style**: HTML5, CSS3 (Flexbox, CSS Grid, Custom Variables)
- **Logic**: Vanilla JavaScript (ES6)
- **AI / ML**: TensorFlow.js (`@tensorflow/tfjs`), `@tensorflow-models/mobilenet`
- **Data Visualization**: Chart.js
- **Icons & Typography**: FontAwesome, Google Fonts (Poppins & Open Sans)

## 💻 How to Run Locally
Because this prototype is entirely self-contained, no complex server setup is required to evaluate it.
1. Download or extract the project folder.
2. Double-click on the `index.html` file to open it in any modern web browser (Google Chrome, Microsoft Edge, Safari).
3. Scroll down to the **Live Demo** section to test the AI camera scanner or file upload features!
